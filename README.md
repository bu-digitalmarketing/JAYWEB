# JAYWEB

เว็บไซต์สแตติก 2 ส่วนในโปรเจกต์เดียว ไม่ต้อง build ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ผ่านเว็บเซิร์ฟเวอร์ได้เลย

| หน้า | ไฟล์ | คำอธิบาย |
|---|---|---|
| เว็บส่วนตัว | `index.html` | โปรไฟล์ ประวัติ ทักษะ ผลงาน ช่องทางติดต่อ |
| ราคาทองวันนี้ | `gold/index.html` | ราคาทองคำแท่ง/ทองรูปพรรณ ตามประกาศสมาคมค้าทองคำ |

ธีมสีสายรุ้ง รองรับโหมดสว่าง/มืดอัตโนมัติ และแสดงผลได้ทั้งมือถือและเดสก์ท็อป

## โครงสร้างไฟล์

```
index.html                  หน้าเว็บส่วนตัว
assets/css/style.css        สไตล์เว็บส่วนตัว
assets/js/data.js           ⭐ ข้อมูลส่วนตัวทั้งหมด แก้ที่ไฟล์นี้ไฟล์เดียว
assets/js/main.js           ตัวสร้างหน้าเว็บจาก data.js

gold/index.html             หน้าเว็บราคาทอง
gold/assets/css/gold.css    สไตล์เว็บราคาทอง
gold/assets/js/gold-data.js ข้อมูลสำรอง (ใช้เมื่อดึงข้อมูลสดไม่ได้)
gold/assets/js/gold.js      ตัวดึงข้อมูลสด กราฟ ตาราง และเครื่องคำนวณ
```

## แก้ข้อมูลส่วนตัว

เปิด `assets/js/data.js` แล้วแก้ข้อความในเครื่องหมาย `" "` ได้เลย
ช่องไหนยังไม่มีข้อมูลให้ใส่ `""` ระบบจะซ่อนส่วนนั้นให้อัตโนมัติ

## ที่มาข้อมูลราคาทอง

ราคาอ้างอิงประกาศของสมาคมค้าทองคำ ดึงสดผ่าน `https://api.chnwt.dev/thai-gold-api/latest`
รีเฟรชอัตโนมัติทุก 60 วินาที ถ้าดึงไม่สำเร็จจะสลับไปใช้ค่าใน `gold/assets/js/gold-data.js` แทน

> ข้อมูลเพื่อการอ้างอิงเท่านั้น ราคาซื้อขายจริงขึ้นอยู่กับร้านทองแต่ละร้าน ไม่ใช่คำแนะนำการลงทุน

## เปิดดูในเครื่อง

ถ้ามี Python: `python3 -m http.server 4173`
ถ้ามี Ruby: `ruby -run -e httpd . -p 4173`

แล้วเปิด <http://localhost:4173/> (เว็บส่วนตัว) และ <http://localhost:4173/gold/> (ราคาทอง)
